As some people probably guessed, this page didn't have a survey or anything. It was just a loading GIF.

However, I did collect data from this experiment. The page created a giant random number to identify the client and sent it to the server every second along with a piece of information saying whether the tab is in focus. It also stored that random number in local storage so if you tried to reload the page it would use thst same number. This means it is still possible to tell that it is the same person viewing the page in the server's log file. The only thing that I wasn't able to track is if someone viewed it on multiple devices in which case it would be interpreted as different people.

Just to be clear, the server didn't record IP addresses (which would be usless anyway), User-Agent headers (The type of device your using) or anything like that. So I wasn't spying on anyone.
